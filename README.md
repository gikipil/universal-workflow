# 🧩 Универсальный воркфлоу

**Версия 0.4.0 · ComfyUI**

Собираю workflow, в котором можно генерировать изображения и дорабатывать результат через удобный интерфейс. Все основные настройки находятся под рукой, дополнительные открываются по шестерёнке. Сейчас доступны генерация на Krea, общая детализация на Krea или Z-Image, локальная обработка лица, рук и масок, а также апскейл. Дальше буду добавлять другие способы обработки.

## 🎯 Что умеет

| Возможность | Для чего нужна |
| --- | --- |
| 🎨 Три способа генерации | Обычный сэмплер, RES4LYF и Raw → Turbo. Можно выбрать подходящий под свой результат. |
| 🧩 LoRA | Отдельные наборы для генерации и детализации. Наборы Krea и Z-Image переключаются автоматически вместе с моделью второго прохода. Постоянные LoRA настраиваются отдельно. В обычные списки можно добавлять слоты и удалять добавленные. |
| 🎚️ Слайдеры LoRA | Отдельные окна для генерации и детализации: сила бегунком или числом, своя подсказка и диапазон у каждого слайдера. |
| 📐 Размер кадра | Ручная ширина и высота, популярные соотношения сторон и выбор мегапикселей. |
| ✨ Второй проход | Дополнительная проработка изображения. Можно выбрать Krea или Z-Image, настроить силу изменения или полностью отключить этап. |
| 🎯 Лицо, руки и маски | Лицо, руки, область по описанию через SAM 3.1 и ручная маска. Режимы включаются независимо, порядок можно менять. |
| 🔍 Сравнение | Итог, первый проход и сравнение до/после находятся в отдельных вкладках. |
| 📈 Апскейл | Simple, Ultimate и SeedVR. Общий размер результата, отдельные настройки и модели каждого режима. |
| ⏳ Ход обработки | Название текущего этапа и операции, шаги текущего сэмплирования и общий процент включённой цепочки. |
| 💾 Сохранение | Включается отдельным переключателем. По умолчанию выключено. |

## 🎛️ Как пользоваться

1. Напиши промт для первого кадра и подключи нужные LoRA.
2. Выбери способ генерации стрелками. Параметры выбранного способа открываются шестерёнкой справа.
3. Задай размер изображения и Seed. Зафиксированный Seed удобен для сравнения разных настроек на одном кадре.
4. Если нужна детализация, выбери модель второго прохода и настрой **denoise** — силу перерисовки. Его промт и дополнительные параметры тоже находятся под шестерёнкой.
5. При необходимости включи режимы блока **«3 · Лицо, руки и маски»**, настрой области и их порядок. По умолчанию все четыре выключены.
6. Если нужно увеличение, включи **«4 · Апскейл»**, выбери режим и размер результата.
7. Нажми **«Сгенерировать»** и сравни результат с первым проходом. Если хочешь сохранить файл, включи переключатель сохранения.

По умолчанию генерация работает в режиме **Raw → Turbo**, а детализация — **Z-Image · RES4LYF**. SNOFS v1.6 уже подключена для Krea, добавлять её в пользовательский слот повторно не нужно.

## 🧩 Обычные LoRA

В списках генерации и детализации изначально по пять слотов. Кнопка **«Добавить LoRA»** снизу добавляет новый. Дополнительный слот можно удалить крестиком справа; первые пять остаются на месте.

Для Krea и Z-Image в детализации сохраняются собственные списки, включая добавленные слоты. Включение, выбор файла и сила каждой LoRA настраиваются в её строке. Окно выбора использует тот же поиск по папкам и оформление, что и у слайдеров.

## 🎚️ Слайдеры

Кнопка **«Слайдеры»** находится у первых двух этапов, между его настройками и списком LoRA. Для генерации открывается набор Krea. У детализации свои независимые наборы Krea и Z-Image — кнопка открывает набор выбранной модели.

В каждом окне сначала **шесть слотов в две колонки**. Слева от линии можно вручную задать силу, а точкой на линии — менять её бегунком. Под линией отображается твоя подсказка о действии слайдера.

Нажми шестерёнку справа, чтобы выбрать LoRA, написать подсказку и указать рекомендуемый диапазон. Затем нажми **«Сохранить»**. Диапазон ограничивает бегунок; длина линии всегда одинаковая. Изменение границ не меняет уже установленную силу — число можно задать и за пределами рекомендуемого диапазона.

Кнопка **«Добавить ряд»** снизу добавляет ещё два слота. У каждого дополнительного ряда есть кнопка **«Удалить ряд»**; первые шесть слотов остаются. Если в удаляемом ряду уже есть настройки, окно попросит подтвердить удаление. Слайдеры не занимают обычные или постоянные слоты LoRA; их настройки и значения сохраняются вместе с workflow.

## 🎯 Лицо, руки и маски

Третий блок дорабатывает отдельные участки уже сгенерированного кадра. Это детализация, а не отдельный редактор для замены предметов или сцены.

| Режим | Как выбирается область |
| --- | --- |
| 🙂 Лицо | Автоматический детектор лиц. |
| ✋ Руки | Автоматический детектор рук. |
| 🔎 SAM 3.1 | Короткое описание объекта на английском, например `hair` или `jacket`. |
| 🖌️ Ручная маска | Область, нарисованная кистью на текущем кадре. |

Можно включить любой набор режимов. Стрелки **↑ / ↓** меняют порядок: каждый включённый режим получает результат предыдущего. Выключенный передаёт изображение дальше без обработки. Если детектор ничего не нашёл или маска пуста, выделять для детализации нечего.

У каждого режима своя шестерёнка: промт, **denoise**, рабочий размер участка, максимальный размер, мягкость края и контекст вокруг области. Для автоматического выделения доступен порог обнаружения. Общие Seed, шаги, сэмплер и шедулер находятся под шестерёнкой рядом с выбором модели блока.

Для третьего этапа выбирается **Z-Image Turbo** или **Krea Turbo**. Модели и наборы LoRA независимы от первых двух этапов. Кнопка **«Использовать LoRA третьего блока»** в настройках каждого режима позволяет, например, подключить LoRA персонажа для лица, а руки обработать без неё. При смене Krea/Z-Image открывается собственный список LoRA соответствующей модели; подключай совместимые файлы.

**Как нарисовать маску:** сначала получи кадр с выключенным ручным режимом. Открой его настройки → **«Нарисовать / изменить маску»**, закрась нужные участки и нажми **«Сохранить маску»**. Есть размер кисти, ластик и очистка. Затем включи режим и повтори запуск. При смене Seed, позы или композиции проверь маску заново: она привязана к кадру, а не к человеку на нём.

Кнопка **«Посмотреть маску»** показывает выделение после запуска режима. Справа доступны итог, общий результат до/после, первый и второй проходы, а во вкладке **«Лицо, руки и маски»** — отдельные сравнения для лица, рук, SAM и ручной маски.

## ⚙️ Общие настройки

Кнопка **«Настройки»** справа сверху открывает окно на весь экран. Красная кнопка **«Закрыть»** находится в правом верхнем углу.

- **Модели и LoRA** — выбор моделей, энкодеров, VAE и Turbo-адаптеров. У Krea общий комплект для генерации и Krea-детализации, у Z-Image — свой. У третьего этапа отдельный комплект моделей, энкодеров, VAE и Turbo-адаптер. Модели SAM 3.1 и детекторы YOLO для лиц и рук также выбираются здесь. Карточки комплектов расположены компактно в два ряда. Здесь же по три постоянных LoRA для каждого набора: Krea-генерации, Krea-детализации и Z-Image-детализации. Можно выбрать файл, включить слот и задать силу; на основной странице эти LoRA скрыты.
- **Внешний вид** — цветовой профиль и яркость свечения активной вкладки. Доступны стандартный, графитовый, индиго и морской профили.

Выбранные модели, LoRA и оформление сохраняются вместе с workflow. Пустые постоянные слоты можно оставить выключенными.

## 📈 Апскейл

Четвёртый блок получает результат предыдущих этапов. Его можно включить отдельно; при выключении изображение проходит дальше без апскейла. По умолчанию выбран **SeedVR**, переключатель блока изначально выключен.

| Режим | Для чего подходит |
| --- | --- |
| ⚡ Simple Upscale | Быстрое увеличение нейросетевой upscale-моделью без диффузионной перерисовки. В настройках можно выбрать обычный Lanczos. |
| 🧩 Ultimate Upscale | Начальное увеличение своей upscale-моделью, затем обработка тайлов на Z-Image Turbo. Позволяет управлять силой изменения и стыками. |
| 🌱 SeedVR | Увеличение и восстановление деталей; стартовые настройки рассчитаны на одно изображение. |

Стрелки переключают режим, шестерёнка открывает его настройки. **Размер результата общий:** множитель с кнопками ×2 / ×3 / ×4 или длинная сторона с кнопками 2048 / 3072 / 4096. Значение можно ввести вручную, пропорции сохраняются. Начальное значение — ×2.

У **Simple и Ultimate разные загрузчики upscale-моделей**: можно выбрать разные файлы, каждый режим запоминает свой выбор. В общих настройках также доступны отдельные модель Z-Image, энкодер и VAE для перерисовки Ultimate, а для SeedVR — DiT и VAE.

У Ultimate настраиваются промт, Seed, шаги, сэмплер, шедулер, denoise, размеры тайлов, контекст и мягкость краёв, коррекция стыков и тайловое декодирование. CFG = 1, негативное условие нулевое. Начинай с небольшой силы: тайловая обработка может менять фактуры и мелкие формы.

У SeedVR доступны Seed, коррекция цвета, attention, выгрузка блоков DiT на CPU и настройки тайлов VAE. Для 3B доступно до 32 блоков выгрузки, для 7B — до 36. При выборе 3B в общих настройках слишком большое значение автоматически ограничивается 32.

Во вкладке **«Апскейл»** сравниваются вход четвёртого блока и его результат. Итог и сохранение получают результат после апскейла, а при выключенном блоке — кадр после предыдущих этапов. Лицо и руки повторно внутри апскейла не обрабатываются.

## ⏳ Ход обработки

Строка под превью показывает, что выполняется: генерация, второй проход, лицо, руки, SAM, ручная маска или апскейл. Во время подготовки уточняется операция — например, загрузка модели или выделение области.

Счётчик **4/12** относится к текущему сэмплированию, а процент — ко всей включённой цепочке. При Raw → Turbo видно текущую часть; при нескольких локальных участках — номер участка. Для загрузки и других операций без шагов отображается **—**, а не `0/1`. Выключенные режимы не входят в общий прогресс, готовые результаты из кэша учитываются сразу.

Наведением на строку можно посмотреть полное название операции и прошедшее время. Процент отражает ход обработки, а не точную долю оставшегося времени: разные модели и области обрабатываются с разной скоростью.

## 💡 Несколько подсказок

- Чем выше denoise, тем сильнее второй проход меняет изображение. Проверяй лицо, руки, фактуру кожи и ткани через сравнение.
- Для полного отключения детализации выбери **«Второй проход выключен»**. Просто поставить denoise в ноль — не то же самое.
- При смене сцены проверь оба промта. Промт детализации сохраняется, даже когда второй проход выключен.
- Негативный промт доступен в настройках **Raw → Turbo**.
- Детализация не обязана улучшать каждый кадр. Если первый результат нравится больше, второй проход можно не использовать.
- Локальная детализация может менять черты и мелкие формы: начинай с небольшой силы и сравнивай результат. Автоматический детектор иногда пропускает сложные лица или руки — тогда используй ручную маску.
- Локальный рабочий размер третьего блока определяет обработку участка. Размер итогового увеличения задаётся отдельно в четвёртом блоке.

## 📦 How to Install

### 1. Установи ComfyUI и нужные ноды

Кроме самого ComfyUI понадобятся:

- rgthree-comfy;
- RES4LYF;
- Krea-2-Two-Stage-Sampler;
- ComfyUI-Easy-Use;
- ComfyUI-Image-Saver;
- ComfyUI-KJNodes;
- ComfyUI-Custom-Scripts (pysssss);
- ComfyUI_UltimateSDUpscale;
- ComfyUI-SeedVR2_VideoUpscaler;
- [ComfyUI-Impact-Pack](https://github.com/ltdrdata/ComfyUI-Impact-Pack) и [Impact Subpack](https://github.com/ltdrdata/ComfyUI-Impact-Subpack) — локальная детализация и детекторы.

Для SAM 3.1 нужна актуальная версия ComfyUI с нодой **SAM3 Detect**.

Установи их через ComfyUI-Manager вместе с необходимыми зависимостями.

### 2. Установи ND UI Builder

Скачай **[ND UI Builder со страницы разработчика](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder)** и установи по его инструкции. Для этой сборки используй **[совместимую версию ND UI](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder/archive/ad176bd9731c70e2b3246ea9ff1129606591448c.zip)**. В папке `ComfyUI/custom_nodes/` должна быть только одна установленная копия Builder.

### 3. Добавь оформление и управление workflow

Скачай этот репозиторий через **Code → Download ZIP** и распакуй архив. Останови ComfyUI. Из папки **`ui`** скопируй папку **`js`** в установленную папку ND UI Builder, согласившись на замену файлов.

Например:

```text
ui/js → ComfyUI/custom_nodes/ComfyUI-ND-UI-Builder/js
```

Если у установленного Builder другое название папки, копируй в неё. Перед заменой сохрани свою прежнюю папку Builder вне `custom_nodes`. Повторно собирать панель или настраивать её расположение не нужно.

### 4. Добавь модели

Модели и LoRA скачиваются отдельно. Пути указаны относительно `ComfyUI/models/`:

| Файл | Куда положить |
| --- | --- |
| `krea2_raw_fp8_scaled.safetensors` | `diffusion_models/Krea2/` |
| `qwen3vl_4b_fp8_scaled.safetensors` | `text_encoders/Krea2/` |
| `qwen_image_vae.safetensors` | `vae/Krea2/` |
| `krea2_turbo_lora_rank_64_bf16.safetensors` | `loras/Krea2/` |
| `snofs_krea_v1_6.safetensors` | `loras/Krea2/` |
| `cyberrealisticZImage_v50.safetensors` | `diffusion_models/Zimage/` |
| `zImageTurbo_turbo_txt.safetensors` | `text_encoders/ZImage/` |
| `ae_zimgturbo.safetensors` | `vae/ZImage/` |

Для локального блока также нужны:

| Файл | Куда положить |
| --- | --- |
| [sam3.1_multiplex_fp16.safetensors](https://huggingface.co/Comfy-Org/sam3.1/resolve/main/checkpoints/sam3.1_multiplex_fp16.safetensors) | `checkpoints/` |
| `face_yolov8m.pt` | `ultralytics/bbox/` |
| `hand_yolov8s.pt` | `ultralytics/bbox/` |

Детекторы устанавливаются через менеджер моделей Impact Pack/ComfyUI-Manager. Файл **`assets/universal-local-empty-mask.png`** из этого репозитория скопируй в **`ComfyUI/input/`**. Это пустая маска, фотографии для старта не нужны. Нарисованные маски сохраняются в `input/universal-masks/`; при переносе собственных настроенных масок скопируй и эту папку.

Для апскейла в стартовой конфигурации используются:

| Файл | Куда положить |
| --- | --- |
| `4x_NMKD-Siax_200k.pth` | `upscale_models/` |
| `seedvr2_ema_7b-Q4_K_M.gguf` | `SEEDVR2/` |
| `ema_vae_fp16.safetensors` | `SEEDVR2/` |

Simple и Ultimate изначально указывают один файл, но это независимые загрузчики: любой можно заменить в настройках. SeedVR использует загрузчики своей ноды, поддерживающие скачивание выбранных весов при первом использовании. Для Ultimate нужен совместимый комплект Z-Image из таблицы выше; файлы могут использоваться повторно без копирования.

Собственные LoRA положи в `models/loras/` и выбери в загрузчиках. Если используешь другие имена файлов или подпапки, поменяй соответствующий выбор в нодах.

### 5. Открой workflow

Перезапусти ComfyUI, обнови страницу **Ctrl+F5** и перетащи в неё **`workflow.json`**. Затем нажми **ND UI**, чтобы открыть готовую панель.

Если появляются неизвестные виджеты, проверь, что дополнения из `ui/js` скопированы в нужную папку, и ещё раз обнови страницу. Если ComfyUI сообщает об отсутствующей ноде или модели, сначала установи её.

Оформление, расположение элементов и привязки управления уже сохранены. Для переноса на другой ПК нужны `workflow.json`, дополнения из `ui`, оригинальный ND UI Builder, остальные ноды и модели.

Интерфейс сделан на основе **[ND UI Builder](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder)** от Neural Dreamer. Дополнения к его коду распространяются по **[AGPL-3.0](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder/blob/main/LICENSE)**.
