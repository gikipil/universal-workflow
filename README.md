# 🧩 Универсальный воркфлоу

**Версия 0.9.1 · ComfyUI**

Собираю workflow, в котором можно генерировать изображения и дорабатывать результат через удобный интерфейс. Все основные настройки находятся под рукой, дополнительные открываются по шестерёнке. Сейчас доступны генерация на Krea, общая детализация на Krea или Z-Image, локальная обработка лица, рук и масок, а также апскейл. Отдельные вкладки позволяют редактировать фотографии на Qwen Edit 2511 или Krea Edit V2, удалять фон и увеличивать готовые изображения. Дальше буду добавлять другие способы обработки.

## 🎛️ Как пользоваться

1. Напиши промт для первого кадра и подключи нужные LoRA.
2. Выбери способ генерации стрелками. Параметры выбранного способа открываются шестерёнкой справа.
3. При необходимости включи **«Поза по референсу»** сверху слева и загрузи фото. Задай размер изображения и Seed. Зафиксированный Seed удобен для сравнения разных настроек на одном кадре.
4. Если нужна детализация, выбери модель второго прохода и настрой **denoise** — силу перерисовки. Его промт и дополнительные параметры тоже находятся под шестерёнкой.
5. При необходимости включи режимы блока **«3 · Лицо, руки и маски»**, настрой области и их порядок. По умолчанию все четыре выключены.
6. Если нужно увеличение, включи **«4 · Апскейл»**, выбери режим и размер результата.
7. Нажми **«Сгенерировать»** и сравни результат с первым проходом. Если хочешь сохранить файл, включи переключатель сохранения.

Turbo-адаптер Krea выбирается **один раз** в общих настройках и используется для генерации, детализации, локальной обработки, Krea Edit и Ultimate.

По умолчанию генерация работает в режиме **Raw → Turbo**, а детализация — **Z-Image · RES4LYF**. SNOFS v1.6 уже подключена для Krea, добавлять её в пользовательский слот повторно не нужно.

## ✏️ Редактирование

Выбери сверху **«Редактирование»**. Стрелками выбери **Qwen Edit 2511** или **Krea Edit V2**. Фото, маска, инструкция и просмотр результата общие для обоих способов. Кнопка **«Редактировать»** обрабатывает только загруженный кадр.

1. Загрузи основное фото в **Picture 1** слева.
2. При необходимости добавь **Picture 2** — вещь, предмет, цвет или окружение для примера. Этот вход можно оставить пустым: он не участвует в обработке. Кнопка **«Очистить»** убирает референс.
3. Для изменения отдельного участка нажми **«🖌️ Маска»** под первым фото, закрась нужную область и сохрани маску. Режим **«По маске»** включится автоматически. Без него редактируется весь кадр.
4. Напиши, что изменить и что сохранить. Либо выбери готовую инструкцию и нажми **«Вставить в промт»**. Уточни фрагменты в квадратных скобках. Сам выбор в списке не заменяет твой текст.
5. Нажми **«Редактировать»**. Справа доступны итог и сравнение с исходником. Сохранение включается отдельно и изначально выключено.

**Маска:** есть кисть, ластик, очистка рисунка и удаление маски. Приближай колёсиком или кнопками −/＋; перемещай изображение с зажатым пробелом, средней кнопкой мыши либо включив ✋. «Вписать» возвращает изображение целиком. Размер кисти задаётся в пикселях исходника, сохранённая маска сохраняет исходное разрешение. При замене основного фото маска сбрасывается. За пределами мягкого края результат берётся из исходника, приведённого к размеру обработки. Мягкость края настраивается под шестерёнкой редактора. Пустую маску нельзя сохранить; выключатель «По маске» позволяет вернуться к полному кадру, сохранив нарисованную область для повторного использования.

Готовые инструкции: замена одежды, лица и фона, смена позы, доработка скетча до фотографии, изменение цвета, естественный свет, удаление или добавление предмета, восстановление фактуры и свободное изменение. Для замены лица второй снимок задаёт внешность; для позы — положение тела; для скетча — материалы, цвета или желаемый готовый вид. Вариант инструкции учитывает, загружен ли второй референс. Без второго снимка новую одежду или обстановку нужно описать словами.

В конце левой колонки есть **«Апскейл результата»**: включи его при необходимости и выбери Simple, Ultimate или SeedVR. По умолчанию блок выключен, выбран SeedVR. Итог и сохранение получат увеличенный кадр; дополнительная вкладка сравнения показывает результат до/после апскейла. Размер, Seed и параметры прохода настраиваются отдельно; модели апскейла и загрузчики SeedVR общие.

Seed и необязательные LoRA находятся слева. У Qwen и Krea свои наборы пользовательских LoRA и параметры прохода: при переключении они восстанавливаются автоматически. Под шестерёнкой — размер обработки обоих входов, шаги, denoise, сэмплер, шедулер, Shift и мягкость маски. CFG и Double Ref доступны для Qwen.

Для **Krea** в настройках режима выбери один адаптер: **General Edit V2** для изменения кадра по инструкции или **Identity Edit V2** для переноса внешности. По умолчанию выбран **General**. Сами файлы обоих адаптеров выбираются в **⚙️ Настройки → Модели и LoRA → Редактирование · Krea**. Их можно назначить из интерфейса, даже если файлы лежат в другой подпапке. Адаптер подключается автоматически и не занимает пользовательский слот. Для переноса внешности используй основной кадр в Picture 1 и человека в Picture 2.

Krea Edit использует комплект Krea и общий Turbo-адаптер из настроек приложения. Выбирать те же файлы повторно не нужно. Её пользовательские LoRA независимы от LoRA генерации. Qwen использует собственные модель, энкодер и VAE; для замены одежды начни без дополнительных LoRA.

По умолчанию длинная сторона основного кадра — **1920 px**, второго — **1280 px**; пропорции сохраняются с округлением до кратности 16. Редактирование лучше делать до финального апскейла. **2048 px** ранее давали приемлемый результат, но медленно; на **4096 px** появлялись искажения. Просьба сохранить лицо, комнату или позу в промте не гарантирует их точного совпадения.

## 🧽 Удаление фона

Сверху выбери вкладку **«Удаление фона»**. Это отдельная функция внутри того же workflow: её запуск не генерирует новый кадр и не запускает детализацию или апскейл. Настройки и результаты вкладки «Генерация» сохраняются.

1. Загрузи фото слева: нажми на область изображения, перетащи файл или вставь его из буфера.
2. При необходимости выбери модель стрелками. По умолчанию — **RMBG-2.0**; также доступны INSPYRENET, BEN и BEN2. Выбор доступен и в общих настройках.
3. Нажми **«Удалить фон»** снизу. Справа появится результат с прозрачностью; соседние вкладки показывают сравнение и маску.
4. Для сохранения PNG в папку результатов включи **«Сохранять результат»**. По умолчанию сохранение выключено. Картинку также можно скачать из превью.

Основные элементы такие же, как в генерации: фото и параметры слева, результат справа, общая кнопка настроек сверху, прогресс, очередь и сохранение под результатом, широкая кнопка запуска снизу. Шахматная подложка помогает видеть прозрачные участки; в сам PNG она не добавляется.

Шестерёнка открывает разрешение обработки, чувствительность, мягкость края, расширение/сжатие маски и уточнение цвета по краям. **Разрешение обработки влияет на выделение объекта, а размер результата остаётся исходным.** В маске белое — объект, чёрное — удаляемый фон.

Если выбранной модели нет, поле в общих настройках помечается **«потеряно»**; нода может скачать её файлы при первом запуске. Отделение волос и полупрозрачных краёв нужно оценивать на конкретной фотографии.

## 🦴 Поза по референсу

По умолчанию режим выключен: видна только строка с переключателем, генерация использует прежнюю ветку. После включения появляются загрузка фото, сила позы, просмотр последнего скелета и шестерёнка настроек. При выключении эти элементы скрываются; фото и значения сохраняются.

Загрузить фото можно нажатием на область изображения, перетаскиванием или вставкой из буфера.

Фото служит источником скелета. Внешность персонажа, одежду, место и свет по-прежнему задают промт и пользовательские LoRA. Исходное фото не становится стартовым изображением для перерисовки. Размер результата задаётся обычными полями генерации; для близкой композиции выбирай пропорции референса.

**OpenPose LoRA подключается и отключается вместе с режимом**, не занимает пользовательские слоты. Её файл и два детектора выбираются в общих настройках. В настройках позы доступны разрешение детектора и ориентиры лица/кистей. Начальная сила — 1.

Просмотр показывает скелет последней генерации с позой. После замены фото или настроек обновится при следующем запуске. Проверяй суставы: ошибки детекции и перекрытия конечностей могут искажать позу.

Режим подключён к трём способам генерации. Используемый адаптер рассчитан на **Krea Turbo**; сочетание с **Raw → Turbo** требует отдельной проверки результата. Качество переноса позы в этой сборке ещё не проверено генерацией.

## 🧩 Обычные LoRA

В списках генерации и детализации изначально по пять слотов. Кнопка **«Добавить LoRA»** снизу добавляет новый. Дополнительный слот можно удалить крестиком справа; первые пять остаются на месте.

Для Krea и Z-Image в детализации сохраняются собственные списки, включая добавленные слоты. Включение, выбор файла и сила каждой LoRA настраиваются в её строке. Окно выбора использует тот же поиск по папкам и оформление, что и у слайдеров.

## 🎚️ Слайдеры

Кнопка **«Слайдеры»** находится у первых двух этапов, между его настройками и списком LoRA. Для генерации открывается набор Krea. У детализации свои независимые наборы Krea и Z-Image — кнопка открывает набор выбранной модели.

В каждом окне сначала **шесть слотов в две колонки**. Слева от линии можно вручную задать силу, а точкой на линии — менять её бегунком. Под линией отображается твоя подсказка о действии слайдера.

Нажми шестерёнку справа, чтобы выбрать LoRA, написать подсказку и указать рекомендуемый диапазон. Затем нажми **«Сохранить»**. Диапазон ограничивает бегунок; длина линии всегда одинаковая. Изменение границ не меняет уже установленную силу — число можно задать и за пределами рекомендуемого диапазона.

Кнопка **«Добавить ряд»** снизу добавляет ещё два слота. У каждого дополнительного ряда есть кнопка **«Удалить ряд»**; первые шесть слотов остаются. Если в удаляемом ряду уже есть настройки, окно попросит подтвердить удаление. Слайдеры не занимают обычные или постоянные слоты LoRA; их настройки и значения сохраняются вместе с workflow.

## 🎯 Лицо, руки и маски

Третий блок дорабатывает отдельные участки уже сгенерированного кадра. Это детализация, а не отдельный редактор для замены предметов или сцены.

| Режим | Как выбирается область |
| --- | --- |
| 🙂 Лицо | Автоматический детектор лиц. |
| ✋ Руки | Автоматический детектор рук. |
| 🔎 SAM 3.1 | Короткое описание объекта на английском, например `hair` или `jacket`. |
| 🖌️ Ручная маска | Область, нарисованная кистью на текущем кадре. |

Можно включить любой набор режимов. Стрелки **↑ / ↓** меняют порядок: каждый включённый режим получает результат предыдущего. Выключенный передаёт изображение дальше без обработки. Если детектор ничего не нашёл или маска пуста, выделять для детализации нечего.

У каждого режима своя шестерёнка: промт, **denoise**, рабочий размер участка, максимальный размер, мягкость края и контекст вокруг области. Для автоматического выделения доступен порог обнаружения. Общие Seed, шаги, сэмплер и шедулер находятся под шестерёнкой рядом с выбором модели блока.

Для третьего этапа выбирается **Z-Image Turbo** или **Krea Turbo**. Модели и наборы LoRA независимы от первых двух этапов. Кнопка **«Использовать LoRA третьего блока»** в настройках каждого режима позволяет, например, подключить LoRA персонажа для лица, а руки обработать без неё. При смене Krea/Z-Image открывается собственный список LoRA соответствующей модели; подключай совместимые файлы.

**Как нарисовать маску:** сначала получи кадр с выключенным ручным режимом. Открой его настройки → **«Нарисовать / изменить маску»**, закрась нужные участки и нажми **«Сохранить маску»**. Есть размер кисти, ластик и очистка. Затем включи режим и повтори запуск. При смене Seed, позы или композиции проверь маску заново: она привязана к кадру, а не к человеку на нём.

Кнопка **«Посмотреть маску»** показывает выделение после запуска режима. Справа доступны итог, общий результат до/после, первый и второй проходы, а во вкладке **«Лицо, руки и маски»** — отдельные сравнения для лица, рук, SAM и ручной маски.

## ⚙️ Общие настройки

Кнопка **«Настройки»** справа сверху открывает окно на весь экран. Красная кнопка **«Закрыть»** находится в правом верхнем углу.

- **Модели и LoRA** — выбор моделей, энкодеров, VAE и Turbo-адаптеров. У Krea общий комплект для генерации и Krea-детализации, у Z-Image — свой. У третьего этапа отдельный комплект моделей, энкодеров, VAE и Turbo-адаптер. Модели SAM 3.1 и детекторы YOLO для лиц и рук также выбираются здесь. Карточки комплектов расположены компактной сеткой. Здесь же по три постоянных LoRA для каждого набора: Krea-генерации, Krea-детализации и Z-Image-детализации. Можно выбрать файл, включить слот и задать силу; на основной странице эти LoRA скрыты.
- **Внешний вид** — цветовой профиль и яркость свечения активной вкладки. Доступны стандартный, графитовый, индиго и морской профили.

Выбранные модели, LoRA и оформление сохраняются вместе с workflow. Пустые постоянные слоты можно оставить выключенными.

Красная метка **«потеряно»** у выбранного файла означает, что он не найден. Наведи на метку, чтобы увидеть причину. Это действует для моделей, энкодеров, VAE, детекторов и апскейлеров. Среди LoRA метка используется только для необходимых Turbo-адаптеров и OpenPose; обычные, постоянные пользовательские LoRA и слайдеры её не показывают. Пустой слот без выбранного файла не считается ошибкой. Для замены нажми на поле и выбери доступный файл.

## 📈 Апскейл

**Нужно увеличить готовое фото:** открой верхнюю вкладку **«Апскейл»**, загрузи исходник слева, выбери режим и размер, затем нажми **«Увеличить изображение»**. Справа — итог и сравнение с исходником. Эта кнопка запускает только апскейл. Сохранение включается отдельно, по умолчанию выключено; стартовый режим — SeedVR, размер ×2.

Такие же три способа доступны отключаемыми блоками в генерации и в конце редактирования. У каждого из трёх мест свои параметры обработки. Модели и загрузчики выбираются один раз и используются во всех трёх местах. Для Simple и Ultimate по-прежнему можно выбрать разные upscale-модели.

Четвёртый блок получает результат предыдущих этапов. Его можно включить отдельно; при выключении изображение проходит дальше без апскейла. По умолчанию выбран **SeedVR**, переключатель блока изначально выключен.

| Режим | Для чего подходит |
| --- | --- |
| ⚡ Simple Upscale | Быстрое увеличение нейросетевой upscale-моделью без диффузионной перерисовки. В настройках можно выбрать обычный Lanczos. |
| 🧩 Ultimate Upscale | Начальное увеличение своей upscale-моделью, затем обработка тайлов на комплекте основной Krea-генерации с её LoRA и Turbo-адаптером. Позволяет управлять силой изменения и стыками. |
| 🌱 SeedVR | Увеличение и восстановление деталей; стартовые настройки рассчитаны на одно изображение. |

Стрелки переключают режим, шестерёнка открывает его настройки. **Размер результата общий:** множитель с кнопками ×2 / ×3 / ×4 или длинная сторона с кнопками 2048 / 3072 / 4096. Значение можно ввести вручную, пропорции сохраняются. Начальное значение — ×2.

У **Simple и Ultimate разные загрузчики upscale-моделей**: можно выбрать разные файлы, каждый режим запоминает свой выбор. Ultimate берёт модель, энкодер и VAE из основной Krea-генерации. У SeedVR общие DiT и VAE: повторно выбирать их для других вкладок не нужно.

У Ultimate настраиваются промт, Seed, шаги, сэмплер, шедулер, denoise, размеры тайлов, контекст и мягкость краёв, коррекция стыков и тайловое декодирование. CFG = 1, негативное условие нулевое. Начинай с небольшой силы: тайловая обработка может менять фактуры и мелкие формы.

У SeedVR доступны Seed, коррекция цвета, attention, выгрузка блоков DiT на CPU и настройки тайлов VAE. Для 3B доступно до 32 блоков выгрузки, для 7B — до 36. При выборе 3B в общих настройках слишком большое значение автоматически ограничивается 32.

Во внутренней вкладке сравнения **«Апскейл»** на странице генерации показываются вход четвёртого блока и его результат. Итог и сохранение получают результат после апскейла, а при выключенном блоке — кадр после предыдущих этапов. Лицо и руки повторно внутри апскейла не обрабатываются.

## ⏳ Ход обработки

Строка под превью показывает, что выполняется: генерация, второй проход, лицо, руки, SAM, ручная маска или апскейл. Во время подготовки уточняется операция — например, загрузка модели или выделение области.

Счётчик **4/12** относится к текущему сэмплированию, а процент — ко всей включённой цепочке. При Raw → Turbo видно текущую часть; при нескольких локальных участках — номер участка. Для загрузки и других операций без шагов отображается **—**, а не `0/1`. Выключенные режимы не входят в общий прогресс, готовые результаты из кэша учитываются сразу.

Наведением на строку можно посмотреть полное название операции и прошедшее время. Процент отражает ход обработки, а не точную долю оставшегося времени: разные модели и области обрабатываются с разной скоростью.

## 💡 Несколько подсказок

- Чем выше denoise, тем сильнее второй проход меняет изображение. Проверяй лицо, руки, фактуру кожи и ткани через сравнение.
- Для полного отключения детализации выбери **«Второй проход выключен»**. Просто поставить denoise в ноль — не то же самое.
- При смене сцены проверь оба промта. Промт детализации сохраняется, даже когда второй проход выключен.
- Негативный промт доступен в настройках **Raw → Turbo**.
- Детализация не обязана улучшать каждый кадр. Если первый результат нравится больше, второй проход можно не использовать.
- Локальная детализация может менять черты и мелкие формы: начинай с небольшой силы и сравнивай результат. Автоматический детектор иногда пропускает сложные лица или руки — тогда используй ручную маску.
- Локальный рабочий размер третьего блока определяет обработку участка. Размер итогового увеличения задаётся отдельно в четвёртом блоке.

### 2. Установи ND UI Builder

Скачай **[ND UI Builder со страницы разработчика](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder)** и установи по его инструкции. Для этой сборки используй **[совместимую версию ND UI](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder/archive/ad176bd9731c70e2b3246ea9ff1129606591448c.zip)**. В папке `ComfyUI/custom_nodes/` должна быть только одна установленная копия Builder.

### 3. Добавь оформление и управление workflow

Скачай этот репозиторий через **Code → Download ZIP** и распакуй архив. Останови ComfyUI. Из папки **`ui`** скопируй папку **`js`** в установленную папку ND UI Builder, согласившись на замену файлов.

Например:

```text
ui/js → ComfyUI/custom_nodes/ComfyUI-ND-UI-Builder/js
```

Если у установленного Builder другое название папки, копируй в неё. Перед заменой сохрани свою прежнюю папку Builder вне `custom_nodes`. Повторно собирать панель или настраивать её расположение не нужно.

### 5. Открой workflow

Перезапусти ComfyUI, обнови страницу **Ctrl+F5** и перетащи в неё **`workflow.json`**. Затем нажми **ND UI**, чтобы открыть готовую панель.

Если появляются неизвестные виджеты, проверь, что дополнения из `ui/js` скопированы в нужную папку, и ещё раз обнови страницу. Если ComfyUI сообщает об отсутствующей ноде или модели, сначала установи её.

Оформление, расположение элементов и привязки управления уже сохранены. Для переноса на другой ПК нужны `workflow.json`, дополнения из `ui`, оригинальный ND UI Builder, остальные ноды и модели.
