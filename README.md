# 🧩 Универсальный воркфлоу

**Версия 0.2.14** · ComfyUI · локальная генерация изображений.

Единая схема с интерфейсом приложения: выбрать режим, настроить кадр и получить результат. Возможности добавляются постепенно; сейчас доступна задача «Генерация».

## 🎯 Возможности

Генерация на Krea с независимым блоком LoRA и необязательная детализация на Krea либо Z-Image.

| Блок | Возможности |
| --- | --- |
| 🎨 Генерация | Krea: обычный сэмплер, RES4LYF или Raw → Turbo. |
| 🧩 LoRA | Пользовательский набор генерации; скрытая SNOFS v1.6 с силой 1. |
| 📐 Кадр | Ширина, высота, популярные пропорции и разрешение в мегапикселях. |
| 🎲 Варианты | Seed и параметры выбранного режима. |
| ✨ Детализация | Krea либо Z-Image, обычный сэмплер или RES4LYF; этап можно выключить. |
| 🧩 LoRA детализации | Отдельные сохранённые наборы Krea и Z-Image, автоматически переключаемые вслед за моделью. |
| 🔍 Просмотр | Итог, сравнение до/после и результат первого прохода. |
| 💾 Сохранение | Включается отдельно; по умолчанию выключено. |

## 🎛️ Как пользоваться

**Режим генерации по умолчанию — Raw → Turbo.** **Детализация — ZIT · RES4LYF.**

1. Напиши позитивный промт: кто в кадре, одежда, место, свет и характер фотографии. Подключи нужные LoRA генерации.
2. Выбери способ генерации. Шестерёнка справа открывает его параметры; негативный промт находится только в настройках Raw → Turbo.
3. При необходимости настрой второй проход: выбери Krea или Z-Image, набор LoRA, Seed и denoise. Параметры выбранного режима и промт детализации находятся под его шестерёнкой.
4. Сравни итог с первым кадром. Для записи файла включи сохранение и нажми «Сгенерировать».

При смене сцены проверь оба позитивных промта. При выключенной детализации её промт недоступен, текст сохраняется. Наборы LoRA Krea и Z-Image независимы; LoRA генерации не подменяются вторым загрузчиком.

## 💡 Подсказки и ограничения

- Первый позитивный промт доступен всегда. Негативное условие применяется в Raw-стадии Raw → Turbo; в дистиллированных режимах CFG = 1 и используется нулевое отрицательное условие.
- Модель Krea фиксирована на Raw. Для обычного и RES4LYF применяется служебный Turbo-адаптер; повторно выбирать Turbo-модель не требуется.
- Denoise определяет силу перерисовки второго прохода. Сравнивай фактуру кожи, ткани, мелкие черты и пальцы: доработка может как улучшать, так и сглаживать их.
- Чтобы пропустить второй этап, выбери «Второй проход выключен». Denoise = 0 не равно обходу: повторное кодирование VAE само может менять пиксели.
- Между этапами передаётся изображение с кодированием VAE выбранной модели; размер сохраняется. Апскейл, face detailer и hand detailer пока не включены.
- Результаты зависят от модели, LoRA, промта и настроек; улучшение каждого кадра не гарантируется. При правках только UI генерации не запускаются.

## 📦 How to Install

### 1. Скачать сборку

Войди в GitHub под аккаунтом с доступом к этому приватному репозиторию. На основной странице выбери **Code → Download ZIP** и распакуй архив. Для актуальной сборки скачивай ветку `main`; для возврата к прошлой версии выбирай её метку `vX.Y.Z`.

В архиве находятся:

| Файл / папка | Что переносится |
| --- | --- |
| `workflow.json` | Ноды и параметры workflow; сохранённые разметка ND UI, тема, цвета, настройки элементов и привязки управления. |
| `vendor/ComfyUI-NeuralDreamer-UI-Builder/` | Полный установленный пакет ND UI с нашими виджетами и изменениями, включая Python-часть, JavaScript и шрифт. |
| `README.md` | Описание возможностей, инструкция и история изменений. |

**Сохранённый дизайн и управление переносятся вместе с этой сборкой.** Одного `workflow.json` для нашего интерфейса недостаточно: нужен и пакет ND UI из репозитория. Несохранённые правки открытой вкладки, браузерный кэш и личные настройки самого ComfyUI не входят в снимок.

### 2. Подготовить ComfyUI и остальные ноды

На новом ПК установи совместимую актуальную версию ComfyUI. В ComfyUI-Manager установи необходимые пакеты и их зависимости:

| Пакет | Для чего нужен |
| --- | --- |
| `rgthree-comfy` | Power LoRA Loader, Seed и сравнение изображений. |
| `RES4LYF` | ClownsharKSampler и соответствующие режимы генерации/детализации. |
| `Krea-2-Two-Stage-Sampler` | Krea2ModelSampling и режим Raw → Turbo. |
| `ComfyUI-Easy-Use` | Переключение веток обработки. |
| `ComfyUI-Image-Saver` | Image Saver Simple. |
| `ComfyUI-KJNodes` | SetNode / GetNode для внутренних соединений. |

Если Manager предлагает установить отсутствующие ноды после загрузки JSON, проверь их названия по этой таблице. Python-зависимости устанавливай в окружение **этой установки ComfyUI**; у Windows Portable это встроенный Python, а не системный. Дополнительных Python-зависимостей у сохранённого ND UI Builder нет.

### 3. Перенести наш ND UI

Останови ComfyUI. Скопируй **папку целиком**:

```text
Из архива:
vendor/ComfyUI-NeuralDreamer-UI-Builder/

На новом ПК:
ComfyUI/custom_nodes/ComfyUI-NeuralDreamer-UI-Builder/
```

Итоговая структура должна содержать файлы непосредственно в этой папке:

```text
ComfyUI/
└── custom_nodes/
    └── ComfyUI-NeuralDreamer-UI-Builder/
        ├── __init__.py
        ├── pyproject.toml
        ├── ndui_py/
        └── js/
```

Не создавай второй вложенный каталог с тем же именем и не ставь рядом ещё одну копию Builder. Если Builder уже установлен, сохрани его прежнюю папку вне `custom_nodes`, затем замени её нашей сборкой. Обычная установка оригинального Builder без наших файлов не содержит специальных виджетов workflow. Обновление оригинального пакета может перезаписать наши изменения; до обновления сохраняй рабочую сборку.

### 4. Перенести модели и LoRA

**Веса моделей и LoRA в репозиторий не включены.** Их нужно скопировать с рабочего ПК либо скачать отдельно. Пути ниже указаны относительно `ComfyUI/models/` и соответствуют сохранённым загрузчикам:

| Назначение | Путь |
| --- | --- |
| Krea Raw | `diffusion_models/Krea2/krea2_raw_fp8_scaled.safetensors` |
| Энкодер Krea | `text_encoders/Krea2/qwen3vl_4b_fp8_scaled.safetensors` |
| VAE Krea | `vae/Krea2/qwen_image_vae.safetensors` |
| Turbo-адаптер Krea | `loras/Krea2/krea2_turbo_lora_rank_64_bf16.safetensors` |
| SNOFS | `loras/Krea2/snofs_krea_v1_6.safetensors` |
| Z-Image | `diffusion_models/Zimage/cyberrealisticZImage_v50.safetensors` |
| Энкодер Z-Image | `text_encoders/ZImage/zImageTurbo_turbo_txt.safetensors` |
| VAE Z-Image | `vae/ZImage/ae_zimgturbo.safetensors` |

Также перенеси собственные LoRA, выбранные в загрузчиках. Если файлы называются иначе или находятся в других подпапках, укажи фактические пути в соответствующих нодах. В некоторых режимах модели подключаются автоматически: отсутствие отдельного выбора модели в UI не означает, что она не нужна.

### 5. Загрузить workflow

1. Запусти или перезапусти ComfyUI после установки нод и моделей.
2. Обнови страницу браузера **Ctrl+F5**.
3. Перетащи `workflow.json` в ComfyUI или открой его через меню загрузки workflow. Для постоянного хранения можно положить его в `ComfyUI/user/default/workflows/`.
4. Проверь отсутствие неизвестных нод и отсутствующих моделей, затем нажми **ND UI** рядом с запуском. Панель уже настроена — собирать её заново не нужно.
5. Проверь выбранные LoRA, промты и размер кадра. Сохранение результата по умолчанию выключено; включи его при необходимости.

**Если появилось `Unknown widget`:** проверь, что скопирована наша папка ND UI целиком, ComfyUI перезапущен и выполнено Ctrl+F5. **Если отсутствует нода:** установи соответствующий пакет из таблицы. **Если не найдена модель:** проверь имя файла и путь в её загрузчике.

### Что проверено

В репозитории сохранены все 303 файла установленного ND UI; их содержимое сверено с рабочим ПК. `workflow.json` содержит конфигурацию интерфейса и совпадает с текущей сохранённой схемой. Установка с нуля на отдельном ПК пока не проверялась; это перенос workflow и интерфейса, а не готовый архив всего ComfyUI с моделями.

Исторические JSON сохранены без изменения байтов. Исходники ND UI — снимок установленной сборки на момент миграции; точной истории прежних изменений общих JS-файлов нет. Авторские лицензии и инструкция ND UI находятся внутри его папки.
