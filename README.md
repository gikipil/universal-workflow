# 🧩 Универсальный воркфлоу

**Русский** · [English](README_EN.md)

**Версия 2.0.0 · ComfyUI · English по умолчанию**

Один интерфейс для генерации изображений, детализации, редактирования, дорисовки, удаления фона, апскейла, описания изображений, видео и звука. Основные настройки слева, результат и сравнения справа, дополнительные параметры открываются по шестерёнке.

**Скачать:** [релиз 2.0.0](https://github.com/gikipil/universal-workflow/releases/tag/v2.0.0) · [полный ZIP](https://github.com/gikipil/universal-workflow/releases/download/v2.0.0/Universal-Workflow-v2.0.0.zip) · [JSON workflow](Universal-Workflow-v2.0.0.json).

**Все версии:** [история версий и загрузка по меткам](https://github.com/gikipil/universal-workflow/tags). В основной ветке находится актуальная версия; предыдущие доступны в том же репозитории.

Одного JSON недостаточно: ниже описана установка интерфейса и локальных модулей. Веса моделей, сторонние ноды и личные фотографии в сборку не входят.

## 📦 How to Install

### Установка для Windows — через мастер

1. Скачай **полный ZIP релиза**, распакуй его целиком и открой `START-HERE.txt`.
2. Закрой ComfyUI и запусти **Install.cmd**. Выбери папку своего ComfyUI или его portable-папку.
3. Дождись проверки. Мастер покажет изменения ComfyUI, нод и пакетов Python. Прочитай план и подтверди установку. Заменяемые файлы сохраняются в резервную копию.
4. Запусти ComfyUI как обычно, обнови страницу **Ctrl+F5**, открой JSON Universal Workflow и нажми **ND UI**.
5. Выбери модели в настройках. В **Help** кнопки скачивают рекомендованные файлы прямо в нужные папки; отдельное создание каталогов не требуется.

В архиве уже есть ND UI Builder с лицензиями, наш интерфейс и локальные модули. Установщик скачивает недостающие исходники нод и библиотеки Python, **но не скачивает веса моделей**. Help — рекомендации автора, а не обязательный список: другие совместимые модели тоже можно выбирать в настройках. Для источников с авторизацией остаётся прямая ссылка для ручной загрузки.

Нужны Windows, интернет и существующий ComfyUI с Python/pip. Полная подготовка видео/звука предназначена для NVIDIA; рекомендуется Python 3.12, совместимость пакетов проверяется; можно выбрать подготовку только изображений без смены линейки PyTorch. Изменения окружения выполняются только после подтверждения. Установка библиотек может занять несколько ГБ. Рабочий процесс не останавливается автоматически — ComfyUI нужно закрыть самостоятельно. Конфликты зависимостей выводятся в журнал и не считаются успешной установкой.

Мастер установки выбирает язык Windows: русский, английский, французский, испанский, упрощённый китайский или японский. Для остальных языков используется английский. Перед проверкой или установкой язык можно сменить в **Language**. Технический журнал остаётся на английском.

Установщик не понижает версии установленных пакетов. Совместимые версии сохраняются, недостающие зависимости устанавливаются, необходимые обновления включаются в план подтверждения. Если зависимости требуют понижения, проверка останавливается без изменений окружения.

### Ручная установка — альтернатива установщику

1. Скачай и полностью распакуй ZIP релиза. Закрой ComfyUI. При этом способе запускать `Install.cmd` не нужно.
2. Скопируй `resources/ND-UI-Builder` в `ComfyUI/custom_nodes/ComfyUI-ND-UI-Builder`. Файл `__init__.py` должен лежать прямо внутри. Оставь только одну копию Builder.
3. Скопируй **содержимое** `resources/package/ui/js/` в папку `js/` этого Builder с заменой совпадающих файлов.
4. Все пять папок из `resources/package/nodes/` скопируй в `ComfyUI/custom_nodes/`. Файл `resources/package/assets/universal-local-empty-mask.png` скопируй в `ComfyUI/input/`.
5. Установи внешние наборы нод из списка ниже через ComfyUI-Manager или по инструкциям авторов. Библиотеки Python ставь в окружение, из которого запускается ComfyUI. Отдельные требования для видео и звука описаны ниже.
6. Перезапусти ComfyUI, обнови страницу **Ctrl+F5**, открой `resources/package/Universal-Workflow-v2.0.0.json` и нажми **ND UI**.
7. Скачай только нужные модели и выбери реальные файлы в настройках. Они могут лежать в корне соответствующей категории моделей или в любой подпапке. Если сохранённый путь помечен как потерянный, выбери свой файл — повторять структуру папок автора не требуется.

### 3. Установи совместимый ND UI Builder и дополнения

В полном ZIP исходники ND UI уже находятся в `resources/ND-UI-Builder/`. Для установки из исходников Git скачай [ND UI Builder у автора](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder). Релиз основан на ревизии `ad176bd9731c70e2b3246ea9ff1129606591448c`: [совместимый ZIP](https://github.com/neural-dreamer/ComfyUI-ND-UI-Builder/archive/ad176bd9731c70e2b3246ea9ff1129606591448c.zip).

Распакуй Builder в `ComfyUI/custom_nodes/ComfyUI-ND-UI-Builder/`, чтобы `__init__.py` лежал прямо внутри. Оставь одну копию Builder. Перед заменой существующей установки сохрани её папку вне `custom_nodes`.

Останови ComfyUI. Объедини **содержимое** `ui/js/` из репозитория с папкой `js/` Builder, заменяя совпадающие файлы:

```text
ui/js/* → ComfyUI/custom_nodes/ComfyUI-ND-UI-Builder/js/*
```

Не создавай дополнительную папку `ui` или `js` внутри `js`. В Git хранятся только дополнения и изменения; полный ZIP также содержит исходники совместимого Builder. Обновление Builder может их затереть — тогда повторно примени файлы совместимого релиза.

### 5. Проверь совместимость дополнительных режимов

**Qwen3-TTS:** рабочая установка использует Transformers 5.5.0 и три исправления совместимости. В [compat/README.md](compat/README.md) есть точная исходная ревизия и команды применения патча. Применяй его только к этой ревизии при остановленном ComfyUI; ради него не нужно обновлять все зависимости существующей установки.

**MiniMax H3:** нужен PyTorch **CUDA 13** с совместимыми драйвером NVIDIA и видеокартой. Проверено: Python 3.12, PyTorch 2.10.0+cu130, ComfyUI 0.37.0. Установи [selflift-Avatar](https://github.com/slmonker/selflift-Avatar) и [MiniMax H3 audio T8](https://github.com/T8mars/comfyui-minimax-h3-audio-T8), включая папку `tools`, затем перезапусти ComfyUI. Нужны штатный Model Sparse Attention (sol-attn) и скомпилированные CUDA-ядра comfy-kitchen. PyTorch — с [официальной страницы](https://pytorch.org/get-started/locally/). Не добавляй TST или другой attention override в видеоветку: он отключает потоковую обработку.

| --- | --- |

| `qwen3vl_4b_fp8_scaled.safetensors` | `models/text_encoders/Krea2/` |

В общем комплекте Krea выбирай **Raw-модель**: Turbo-адаптер применяется автоматически. Для дорисовки Krea используется отдельная Turbo-модель. У Z-Image собственные модель, энкодер и VAE. Qwen 2.1 нужен полный отдельный комплект, файлы 2511 его не заменяют.

SNOFS — заранее назначенная необязательная постоянная LoRA. Выключи её слот в настройках, если не скачиваешь. Остальные пользовательские LoRA и слайдеры необязательны. Генерация, детализация Krea и детализация Z-Image сохраняют независимые наборы.

В настройках выбирай реальные локальные файлы. Сохранённые имена энкодера/VAE Z-Image могут отличаться от загрузки: выбери скачанный файл, не угадывай переименование. Метка **missing / «потеряно»** отмечает обязательные файлы выбранного режима; список — при наведении. Она не проверяет все сторонние библиотеки и необязательные LoRA.


В **Настройки → Модели → Help** у рекомендаций есть кнопки скачивания и прямые ссылки. Папки создаются при загрузке; Help работает независимо от установщика. После обновления Universal Memory перезапусти ComfyUI.

### 7. Открой workflow

Перезапусти ComfyUI, обнови страницу через **Ctrl+F5** и перетащи **`Universal-Workflow-v2.0.0.json`** в ComfyUI. Нажми **ND UI**. По умолчанию English; язык меняется через **Settings → Appearance → Interface language**.

Для первого запуска выбери Generation, назначь комплект Krea и Turbo-адаптер, выключи неустановленные постоянные LoRA. Рефайнер, локальные режимы и апскейл оставь выключенными до первого успешного кадра. Напиши промт и нажми Generate, затем подключай этапы по одному.

## 🎛️ Как пользоваться

Нажимай заголовки блоков 2, 3 и 4, чтобы сворачивать и раскрывать каждый отдельно. Сворачивание не отключает этап; положение каждого блока запоминается в браузере.

- **Генерация:** стрелки выбирают способ, шестерёнка открывает его параметры. По умолчанию Raw → Turbo; негативный промт находится в его настройках. Обычные Turbo-режимы используют CFG 1 и нулевое негативное условие.
- **Детализация:** независимый второй проход. LoRA переключаются вместе с Krea/Z-Image. Чем выше denoise, тем сильнее изменение. «Второй проход выключен» полностью обходит этап. Способ по умолчанию — Z-Image RES4LYF; перед использованием назначь модели.
- **Облегчённая генерация:** в настройках «Обычный · Turbo» и «RES4LYF · Turbo» включи «Облегчённая версия». Используется готовая Turbo-модель из общих настроек Krea2, без Turbo LoRA. Выбор сохраняется отдельно для каждого режима; по умолчанию выключен. Raw → Turbo работает как раньше. Пользовательские LoRA и поза сохраняются. Рефайнер и локальные правки используют свои прежние модели — отключи их, если нужен только облегчённый первый проход.
- **Слайдеры:** для каждого выбери LoRA, подсказку и рекомендуемый диапазон. Значения вне диапазона вводятся числом. Добавленные ряды и слоты удаляются, первоначальные остаются.
- **Поза:** включи переключатель и загрузи референс. Скелет задаёт позу, LoRA и промт — внешность и сцену. Выключение обходит контроль и адаптер. Показанный скелет обновляется после генерации.
- **Локальные режимы:** лицо, руки, SAM и ручная маска включаются независимо, стрелки меняют порядок. Сначала получи кадр, затем рисуй маску. Проверяй её после смены композиции, размера или Seed; сравнивай каждый режим до/после.
- **Редактирование:** основное фото и необязательный второй референс с кнопкой очистки. Qwen 2511, Krea General/Identity или Qwen 2.1. Маска, крупный план, рефайнер и финальный апскейл необязательны. Double Ref находится в Qwen 2511. По возможности редактируй до финального апскейла.
- **Дорисовка:** исходник, способ, рабочий размер и конечный размер либо добавляемые пиксели. Промт описывает продолжение. Исходная область сохраняется с мягким переходом; связность геометрии зависит от модели.
- **Апскейл:** Simple увеличивает через upscale-модель, Ultimate также перерисовывает тайлы общим комплектом Krea, SeedVR восстанавливает и увеличивает. Файлы Simple/Ultimate независимы, комплект SeedVR общий между вкладками. Для готового фото можно сначала включить рефайнер и локальную обработку.
- **Промты:** фото или папка на ПК с ComfyUI, движок и инструкция. Папка обрабатывается без подпапок. Подписи сохраняются рядом с фото с тем же именем, для одиночной загрузки — рядом с копией в input. Существующие подписи можно пропустить; trigger word необязателен.
- **Видео:** одна Hybrid-модель автоматически работает с текстом, первым/последним кадром и референсами. Поля референсов скрыты до добавления через `+`; доступны отдельные первый/последний кадры и до до 9 фото, 3 видео и 3 аудио. Пустые слоты игнорируются. Генерация видео начинается в меньшем разрешении и завершает генерацию в целевом. По умолчанию 6 шагов в низком + 3 в высоком разрешении (8 базовых + 1 финальный); нужен Euler. Отключаемый рефайнер использует ту же модель, свои LoRA и сохраняет звук первого прохода. Рефайнер и SeedVR по умолчанию выключены. Hybrid-модель, общий Turbo V4 и увеличение латента выбираются в настройках видео. Начинай с небольшого размера и длительности.
- **Звук:** речь, голос по референсу/диалог, VoiceDesign или песни. VoiceDesign озвучивает нижний текст описанным голосом. ACE-Step использует стиль и нижние слова; для инструментальной музыки оставь слова пустыми и укажи `instrumental`. Для диалога — `[Speaker_1]:` / `[Speaker_2]:`.

Сохранение включается отдельно и изначально выключено. При экспорте изображений полный граф не встраивается. Для переноса своих масок копируй также `input/universal-masks/` и `input/universal-edit-masks/`.

Строка состояния показывает этап и операцию. Счётчик относится к текущему сэмплированию, процент — ко всей включённой цепочке, а не оставшемуся времени. Очистка памяти перед заданием сохраняет кэш результатов; повторное использование зависит от неизменных входов, Seed и доступного кэша ComfyUI.

Fit / «Вписать» показывает весь результат. `− / +` меняют масштаб просмотра, перетаскивание перемещает изображение, колесо прокручивает страницу. Разрешение результата не меняется.

## 🛠️ Если что-то не загрузилось

| Проблема | Что проверить |
| --- | --- |
| Неизвестный виджет | Ревизия Builder, дополнения в его настоящей `js`, отсутствие дублей, затем Ctrl+F5. |
| Отсутствующая нода | Набор из `dependencies.json` и журнал импорта при запуске. UI не заменяет отсутствующий Python-класс. |
| Нет модели | Полный комплект из Help/MODELS и выбор реальных файлов в настройках. |
| Нет пустой маски | Комплектный PNG в `ComfyUI/input/`. |
| Ошибка конфигурации/токенизатора Qwen Voice | Ревизия QwenTTS, Transformers и инструкция к патчу. |
| Ошибка CUDA / нет нод MiniMax | Используй PyTorch CUDA 13, установи видеосэмплер и T8, выбери модели видео и перезапусти ComfyUI. |
| Нет памяти / очень медленное видео | Уменьши размер, длительность и этапы, проверь свободную VRAM. |

Установка зависит от ОС, GPU и внешних пакетов. Успешный импорт не означает, что все модели поместятся на любом ПК. Включённые цепочки не требуют API-ключей или платных облачных аккаунтов; хостинг отдельных моделей может запросить вход.
