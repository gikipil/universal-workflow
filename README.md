# 🧩 Универсальный воркфлоу

**Версия 0.1.0** · ComfyUI · локальная генерация изображений.

Единая схема с интерфейсом приложения: выбрать режим, настроить кадр и получить результат. Возможности добавляются постепенно; сейчас доступна задача «Генерация».

## 🎯 Возможности

Генерация на Krea с независимым блоком LoRA.

| Блок | Возможности |
| --- | --- |
| 🎨 Генерация | Krea: обычный сэмплер, RES4LYF или Raw → Turbo. |
| 🧩 LoRA | Пользовательский набор генерации; скрытая SNOFS v1.6 с силой 1. |
| 📐 Кадр | Ширина, высота, популярные пропорции и разрешение в мегапикселях. |
| 🎲 Варианты | Seed и параметры выбранного режима. |
| 💾 Сохранение | Включается отдельно; по умолчанию выключено. |

## 🎛️ Как пользоваться

**Режим генерации по умолчанию — Raw → Turbo.**

1. Напиши позитивный промт: кто в кадре, одежда, место, свет и характер фотографии. Подключи нужные LoRA генерации.
2. Выбери способ генерации и настрой его параметры в доступных элементах интерфейса.
3. Выбери размер и Seed, затем нажми «Сгенерировать». Для записи результата отдельно включи сохранение.

## 💡 Подсказки и ограничения

- Первый позитивный промт доступен всегда. Негативное условие применяется в Raw-стадии Raw → Turbo; в дистиллированных режимах CFG = 1 и используется нулевое отрицательное условие.
- Модель Krea фиксирована на Raw. Для обычного и RES4LYF применяется служебный Turbo-адаптер; повторно выбирать Turbo-модель не требуется.
- Результаты зависят от модели, LoRA, промта и настроек; улучшение каждого кадра не гарантируется. При правках только UI генерации не запускаются.

## 📦 Установка и файлы

- `workflow.json` — текущая схема для ComfyUI; этот файл обновляется в истории Git, копии разных версий рядом не хранятся.
- Нужны ComfyUI, rgthree-comfy, RES4LYF, Krea-2-Two-Stage-Sampler, ComfyUI-Easy-Use, ComfyUI-Image-Saver и Set/Get из установленного набора. Обычно SetNode/GetNode предоставляет ComfyUI-KJNodes.
- Наш доработанный интерфейс сохранён в `vendor/ComfyUI-NeuralDreamer-UI-Builder`. На новом ПК помести эту папку в `ComfyUI/custom_nodes`, установи зависимости по её инструкции, перезапусти ComfyUI и обнови браузер Ctrl+F5. При обновлении существующей установки сначала сохрани её изменения.
- Модели не включены. В схеме используются Krea Raw, служебный Turbo-адаптер, SNOFS v1.6 и совместимые текстовый энкодер/VAE; для Z-Image — CyberRealistic Z-Image v50 Turbo и его совместимые CLIP/VAE. Проверь пути к собственным моделям и LoRA.
- Исходники UI сохранены снимком установленной сборки при переносе. Точная прежняя история общих JS-файлов не восстанавливается; исходные JSON сохранены без изменения байтов. Лицензии ND UI находятся внутри его папки.
